Set up Wi-Fi for the Solar Flare Alert

The browser cannot save a network on this lamp. Use the program below on this computer.

Plug the Solar Flare Alert into this computer with a USB cable that carries data.

If the light is not blinking, the Solar Flare Alert is already running and has already joined a Wi-Fi network. You can leave that network as it is, or save a different one with the program below.

Download the setup program

Open Terminal and go to the folder where you saved the file. On a Mac, that folder is usually Downloads. The program asks for the network name and the password.

cd ~/Downloads
python3 lamp_setup.py wifi

You type the password into that program, and the program writes it to the lamp over the cable. The password is not sent to a server. Leave it empty if the network does not have one.

To remove the saved Wi-Fi network, run the command below instead. The program on the lamp stays as it is. The light blinks until a new network is saved.

cd ~/Downloads
python3 lamp_setup.py clear
