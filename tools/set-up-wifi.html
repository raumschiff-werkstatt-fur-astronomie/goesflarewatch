Set up Wi-Fi for the Solar Flare Alert

The browser cannot write to this lamp. A program on the computer can.

Plug the Solar Flare Alert into this computer with a USB cable that carries data.

When the light is not blinking, the Solar Flare Alert is already running and has already joined a Wi-Fi network. You can leave it as it is, or save a different network with the program below.

Download the setup program

Open Terminal. Go to the folder where this file was saved. On a Mac that is usually Downloads. The program asks for the network name and the password.

cd ~/Downloads
python3 lamp_setup.py wifi

The password is typed into that program and written to the lamp over the cable. It is not sent to a server. Leave it empty when the network has no password.

To remove the saved Wi-Fi, run this instead. The program on the lamp stays as it is. Afterwards the light blinks until a new network is saved.

cd ~/Downloads
python3 lamp_setup.py clear
