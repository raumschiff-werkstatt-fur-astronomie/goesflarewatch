Solar Flare Alert Set up Wi-Fi Versions

Set up Wi-Fi for the Solar Flare Alert

When the light is blinking, the lamp is not connected to the Wi-Fi. On a phone, join the Wi-Fi network named Solar Flare Alert. It has no password. It is only the lamp.

The phone should open a setup page. Choose a network and enter its password. The password stays on the lamp. A network that asks for a username while connecting cannot be used. If that is your only network, turn on the phone's personal hotspot, give it a name and a password, and choose that name on the page. The lamp then uses the phone's mobile data.

If the phone does not open the page, open the browser and go to http://192.168.4.1. After the lamp joins, it restarts. The light blinks once more, then it stays on. You can leave Solar Flare Alert and return to your own Wi-Fi.

To choose a different network later, switch that network off and turn the lamp off and on. The light blinks, and Solar Flare Alert appears again.

The phone setup is part of the current software version. Put that version on the lamp from the Versions page. Until then, the lamp does not open a network named Solar Flare Alert.

If the light is not blinking, the lamp has already joined a Wi-Fi network. You can leave that network as it is.

With a computer, you can set up the lamp from a terminal.

Plug the Solar Flare Alert into this computer with a USB cable that carries data.

Download the setup program

Open Terminal and go to the folder where you saved the file. On a Mac or a PC, that folder is usually Downloads. The program lists the networks the lamp can see. Choose one, and then enter the username and the password.

cd ~/Downloads
python3 lamp_setup.py wifi

The password is written to the lamp over the cable and is not sent to a server. Leave the username empty if the network does not use one. Leave the password empty if the network does not use one.

To remove the saved Wi-Fi network, run the command below. The program on the lamp stays as it is. The light blinks until a new network is saved.

cd ~/Downloads
python3 lamp_setup.py clear
