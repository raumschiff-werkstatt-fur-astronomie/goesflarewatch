Solar Flare Alert Set up Wi-Fi Versions

Set up Wi-Fi for the Solar Flare Alert

The browser cannot save a network on this lamp. Use the program below on this computer.

Plug the Solar Flare Alert into this computer with a USB cable that carries data.

If the light is not blinking, the Solar Flare Alert is already running and has already joined a Wi-Fi network. You can leave that network as it is, or save a different one with the program below.

Download the setup program

Open Terminal and go to the folder where you saved the file. On a Mac or a PC, that folder is usually Downloads. The program lists the networks the lamp can see. Choose one, and then enter the username and the password.

cd ~/Downloads
python3 lamp_setup.py wifi

The password is written to the lamp over the cable and is not sent to a server. Leave the username empty if the network does not use one. Leave the password empty if the network does not use one.

To remove the saved Wi-Fi network, run the command below. The program on the lamp stays as it is. The light blinks until a new network is saved.

cd ~/Downloads
python3 lamp_setup.py clear
