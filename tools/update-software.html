Solar Flare Alert Set up Wi-Fi Versions

Solar Flare Alert versions

The browser cannot check this lamp. Use the program below on this computer.

Plug the Solar Flare Alert into this computer with a USB cable that carries data.

Download the setup program

Open Terminal and go to the folder where you saved the file. On a Mac or a PC, that folder is usually Downloads. This check reads the version from the lamp and reports whether the lamp is connected to the Wi-Fi. It does not change the program or the Wi-Fi setup.

cd ~/Downloads
python3 lamp_setup.py check

To put the current software version on the lamp, run the command below. The saved Wi-Fi will not be affected.

cd ~/Downloads
python3 lamp_setup.py install
