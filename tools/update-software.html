Solar Flare Alert versions

The browser cannot check this lamp. A program on the computer can.

Plug the Solar Flare Alert into this computer with a USB cable that carries data.

Download the setup program

Open Terminal. Go to the folder where this file was saved. On a Mac that is usually Downloads. This reads the version. It does not change the program or the Wi-Fi.

cd ~/Downloads
python3 lamp_setup.py check

To put the current version on the lamp, run this instead. The saved Wi-Fi stays as it is. The external Wi-Fi manager stays as it is.

cd ~/Downloads
python3 lamp_setup.py install
